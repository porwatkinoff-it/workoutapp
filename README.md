# powerout — дневник тренировок

Приложение для Android и iOS, в котором можно вести программу по неделям, выбирать удобные дни тренировок, записывать вес и повторы в каждом подходе и смотреть прошлые результаты.

Интерфейс на русском языке. План, результаты и история хранятся на устройстве и доступны без интернета. Для загрузки таблиц и распознавания фотографий нужен отдельный сервис импорта.

## Что умеет приложение

- Показывает программу по неделям и дням: упражнения, подходы, повторы, отдых, разминку и примечания.
- Позволяет выбрать свои дни тренировок для одной недели или всей программы.
- Переносит отдельное упражнение на другой день или неделю с сохранением записанных результатов.
- Сохраняет вес и количество повторений каждого подхода, отметку выполнения и заметки.
- Позволяет добавлять подходы и использовать таймер отдыха.
- Показывает историю за любой сохранённый месяц и день, а также результаты конкретного упражнения.
- Предлагает выбор источника загрузки: фотографии из медиатеки или документы из файлов. Загружает программы из CSV и Excel, распознаёт фотографии через сервис импорта и даёт проверить результат перед добавлением.
- Сообщает о новой версии на GitHub и открывает скачивание обновления.
- Создаёт резервную копию плана и журнала и восстанавливает её из JSON-файла.

## Разделы приложения

| Раздел | Для чего нужен |
| --- | --- |
| **План** | Выбор недели и дня, просмотр упражнений, настройка дней тренировок и запись результатов. |
| **Журнал** | История тренировок, поиск упражнений, просмотр подходов, веса, повторов и заметок. |
| **Загрузка** | Импорт программы, проверка черновика, скачивание шаблона CSV и восстановление резервной копии. |
| **Настройки** | Проверка обновлений, дата начала программы, адрес сервиса импорта, резервное копирование и очистка примера программы. |

## Начало работы

1. Откройте **«План»**. В приложении уже есть пример программы на четыре недели. Его можно использовать, изменить или заменить своей программой.
2. В **«Настройки» → «Начало программы»** задайте понедельник, с которого начинается первая неделя. Это начало календарной недели — сами тренировки могут проходить в любые выбранные вами дни.
3. В плане нажмите **«Дни тренировок»** и настройте расписание.
4. Откройте нужное упражнение кнопкой **«+ Результат»**, запишите подходы и сохраните результат.
5. Во вкладке **«Журнал»** смотрите историю и сравнивайте нагрузку с прошлыми тренировками.

## Уведомления об обновлении

Начиная с версии **1.1.3**, приложение проверяет опубликованные релизы на GitHub при запуске. При возвращении в приложение повторная проверка выполняется, если с предыдущей попытки прошло не менее 6 часов. Проверяется только стабильный релиз с готовым APK или IPA для вашей платформы.

Если вышла новая версия, внутри приложения появляется сообщение с кнопками **«Скачать обновление»** и **«Позже»**. Кнопка «Позже» скрывает сообщение до следующего запуска; ссылка на найденную версию остаётся в **«Настройки» → «Обновления приложения»**. Там же можно проверить обновления вручную.

На Android открывается скачивание APK, на iOS — страница релиза с IPA для самостоятельной подписи. Установка выполняется пользователем. Проверка требует интернета; при недоступной сети план и журнал продолжают работать. Фоновых push-уведомлений при закрытом приложении нет.

Пользователям версий 1.1.2 и ниже нужно один раз вручную установить 1.1.3 или новее — в старых сборках ещё нет этой функции.

## Навигация назад на Android

Системный жест «Назад» от края экрана и системная кнопка «Назад» возвращают к предыдущему открытому разделу. Если открыт выбор источника загрузки или окно редактирования, сначала закрывается оно. Когда предыдущих экранов не осталось, действие передаётся Android.

В разделах также доступна кнопка **«‹ Назад»**. Нижняя панель и окна редактирования учитывают системные отступы, в том числе при управлении жестами.

## Как выбрать дни тренировок

В разделе **«План»** нажмите **«Дни тренировок»**.

1. Выберите неделю программы.
2. Для каждой тренировки укажите удобный день недели.
3. Если расписание должно повторяться, отметьте **«Применить ко всем неделям»**.
4. Нажмите **«Сохранить дни тренировок»**.

Все упражнения тренировки перенесутся вместе. Можно назначить несколько тренировок на один день. Если количество тренировок в разных неделях отличается, настройте эти недели отдельно.

Чтобы перенести только одно упражнение, нажмите рядом с ним **«Перенести / изменить ↗»**, укажите неделю и день и сохраните изменения. Там же можно изменить название упражнения, число подходов, повторы, отдых и примечания. Для нового упражнения используйте кнопку **«+ Добавить упражнение»**.

Изменение расписания не меняет даты уже сохранённых результатов.

## Как записать результат

1. Выберите упражнение в плане и нажмите **«+ Результат»**. Если запись за сегодня уже есть, откройте её кнопкой **«Записано … · Открыть»**.
2. В каждом подходе укажите **вес в килограммах** и **количество повторений**. Например: `42,5 кг × 10`.
3. Отметьте выполненные подходы галочками. Для упражнения с собственным весом укажите `0 кг`.
4. При необходимости добавьте подход кнопкой **«+ Подход»** и напишите заметку.
5. Нажмите **«Сохранить результат»**.

Результат сохраняется на фактическую дату записи, даже если в плане выбран другой день. В статистику и объём нагрузки входят только подходы с галочкой. Повторное открытие того же упражнения в этот день позволяет дополнить запись.

При отметке подхода запускается таймер отдыха. Он работает, пока открыт экран записи; фоновых уведомлений пока нет.

## Как посмотреть результаты месяц назад

1. Откройте **«Журнал»**.
2. Нажмите **«Прошлый месяц»** или перейдите к нужному месяцу стрелками календаря.
3. Выберите день. Точки в календаре отмечают даты с записями.
4. Посмотрите упражнения, число выполненных подходов, вес, повторы и заметки.

Кнопка **«Весь выбранный месяц»** показывает записи за месяц целиком, **«За всё время»** — всю сохранённую историю. Через поле **«Найти упражнение в истории»** можно отфильтровать записи по названию.

Чтобы сразу открыть результаты конкретного упражнения, нажмите **«История»** рядом с ним в плане.

Объём выполненных подходов считается как сумма `вес × повторы`. Например, два подхода по `40 кг × 10` дают общий объём `800 кг`.

## Как загрузить свою программу

Поддерживаются **CSV, Excel (.xlsx), JPG, PNG и WebP** размером до **10 МБ**. Фотографии HEIC на iPhone можно выбирать через «Из медиатеки»: приложение подготовит JPEG для распознавания. При загрузке HEIC через «Из файлов» сначала сохраните изображение в JPG.

**Импорт таблиц и фотографий требует работающего сервиса импорта.** Готовые APK и IPA не включают этот сервер. Его адрес задаётся в **«Настройки» → «Сервис импорта»**; там же есть кнопка **«Проверить связь»**. Для распознавания фотография отправляется по указанному адресу. План, запись результатов, история и восстановление JSON-копии работают без этого сервиса.

Когда сервис настроен:

1. Откройте **«Загрузка» → «Выбрать файл»**.
2. Выберите источник: **«Из медиатеки»** — фотография программы из галереи, **«Из файлов»** — таблица или изображение из файлового менеджера. При необходимости нажмите «Отмена выбора».
3. Выберите нужную фотографию или документ.
4. В черновике проверьте названия, недели, дни, подходы, повторы и примечания. Для исправлений нажмите **«Проверить / изменить»**.
5. Нажмите **«Всё проверено — добавить в план»**.

Распознавание фотографий может ошибаться. Перед добавлением проверьте каждую строку, особенно дни тренировок, разминку и указания к последнему подходу.

Импорт добавляет упражнения к текущему плану. Повторная загрузка того же файла создаст дополнительные экземпляры. Чтобы заменить пример программы, сначала сделайте резервную копию, затем выберите **«Настройки» → «Очистить план упражнений»**. Записи журнала при очистке плана сохраняются.

### Формат таблицы

Готовый шаблон можно получить кнопкой **«Скачать шаблон CSV»** в разделе «Загрузка».

| Колонка | Что указать |
| --- | --- |
| Неделя | Номер недели от 1 до 52. |
| День | День недели от 1 до 7: понедельник — воскресенье. |
| Упражнение | Название упражнения. |
| Подходы | Количество подходов от 1 до 30. |
| Повторы | Например, `8–12` или `15`. |
| Отдых | Время отдыха в минутах. |
| Разминка | Например, `30 и 60%` рабочего веса. |
| Заметки | Указания к выполнению упражнения. |

Первые пять колонок обязательны. Пример CSV с разделителем `;`:

```csv
Неделя;День;Упражнение;Подходы;Повторы;Отдых;Разминка;Заметки
1;2;Тяга штанги в наклоне;3;8–12;3;30 и 60%;
1;4;Жим гантелей;3;8–12;3;60%;
2;2;Тяга штанги в наклоне;4;8–12;3;30 и 60%;
```

## Как сохранить и перенести данные

**Создать копию:** откройте **«Настройки» → «Скачать все данные»** и сохраните файл `workout-backup.json`. В нём находятся программа, дата её начала, результаты и заметки.

**Восстановить копию:** откройте **«Загрузка» → «Выбрать файл» → «Из файлов»**, выберите JSON-файл и подтвердите восстановление. Оно заменит текущий план и журнал, поэтому сначала сохраните копию текущих данных.

Автоматической синхронизации между устройствами пока нет. Для переноса на другой телефон используйте резервную копию.

Удаление приложения или очистка его данных может удалить план и историю. Сохраняйте резервную копию перед переустановкой, сменой телефона или восстановлением другого файла.

## Что важно знать о версии 1.1.3

- Данные хранятся локально, без облачной синхронизации.
- Встроенного общего сервера импорта нет; его нужно подключить отдельно.
- IPA требует подписи сертификатом разработчика пользователя перед установкой.
- Таймер отдыха не присылает фоновые уведомления.
- Подпись APK, содержимое IPA и контрольные суммы проверены. Проверки TypeScript, 22 автоматических теста и 12 сценариев интерфейса прошли; на физических телефонах версия пока не тестировалась.
